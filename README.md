# CabPlay 中文语音导航增强

基于 CabPlay **1.21.0** 的中文语音导航增强版，把语音播报改成了更详细、更自然的中文播报。

## 改进内容

- 时间触发 + 语音时长补偿的三层播报（预告 / 准备 / 现在）
- 近距离连续弯道「然后 X 米后 …」联合播报
- 转弯锁定：当前弯道的「现在」播完前，不提前播下一个弯道
- 车道引导主动播报（左/右第几车道），并降低频率
- 修正中英混播、左右方向、弯道误判等问题
- 环岛「现在驶出环岛」等中文语句

完整的 **ETS2 本地模组安装教程** 见包内 `教程.txt`，或仓库里的 [教程.txt](教程.txt)。
