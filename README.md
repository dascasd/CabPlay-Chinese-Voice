# CabPlay 中文语音导航增强

基于 CabPlay **1.23.0** 的中文语音导航增强，把语音播报改成了更详细、更自然的中文播报。

## 🆕 1.23.0 更新说明

- **适配 1.23.0**：官方改了重置代码结构（`spokenTurns.clear()` + 新缩进），补丁锚点已同步
- **启动器自动修复更新目录**：每次启动都会把 `pickAsset` 改回「优先 ZIP」，防止官方更新装到 `%LOCALAPPDATA%\Programs\CabPlay`

## ✨ 特点

- **三层播报**：预告 → 准备 → 现在（时间触发 + 语音时长补偿，速度自适应）
- **组合弯道**：两个弯道相距 <200m 时合并「右转，然后 150 米后左转」
- **转弯锁定**：当前弯道「现在」播完前，绝不提前播下一个弯道
- **车道引导**：主动播报「请走左侧两车道」「请走右侧第二车道」，并做了降频
- **车道锁定**：当前转弯的车道提示没走完，不播下一个车道提示（避免走错路口）
- **岔路车道**：驶出岔路后带车道提示「驶出右侧岔路，然后按左侧两车道行驶」
- **弯道过滤**：大角度弯道不再误报成转弯
- **偏航 / 到达**：「您已偏航，正在重新规划路线」「前方即将到达目的地」
- **优先级队列**：P0/P1 可打断，P2/P3 排队

## 🚀 推荐用法：启动器（自动打补丁）

官方更新后语音增强会被覆盖。用启动器可以**自动重新打补丁**：

```
CabPlay-Voice-Launcher/
  CabPlayVoice.exe              ← 双击这个（真程序，可固定到开始屏幕/任务栏）
  apply-patch.js                补丁器（用 CabPlay 自带 Node）
  启动 CabPlay(语音增强).bat    备用入口
  launcher.ps1                  启动逻辑
  *.txt                         补丁数据（代码片段 + 翻译）
  patched-version.txt           记录已适配版本
```

**工作流程**：

```
双击 CabPlayVoice.exe
  ↓
检查 app.asar 版本 vs 已适配版本
  ├─ 一致      → 直接启动（带语音增强）
  ├─ 官方更新了 → 自动打补丁（语音增强 + pickAsset 修复）→ 启动
  └─ 打不进（官方大改）→ 提示"需要重新适配" → 以官方原版启动
```

失败时把 `patch-log.txt` 发出来就能重新适配。

## ⚠️ 注意

- CabPlay 会自动更新，更新后语音增强会被覆盖。**请用启动器**，它会自动重新打补丁。
- **不要直接开 `CabPlay.exe`** —— 那样会跳过修复，更新可能装到别的目录。
- 装好后**完全退出 CabPlay 再启动**才会生效。

## 🔧 手动安装（不用启动器）

1. 备份 `CabPlay\resources\app.asar`
2. 用本仓库 Release 里的 `app.asar` 覆盖它
3. 重启 CabPlay
